# 决策树测试语料（测试专用，非课程正式资料）

## 信息熵

信息熵度量随机变量的不确定性。对离散随机变量 X，熵定义为
$H(X) = -\sum_k p_k \log_2 p_k$。熵越小，集合越纯。

## 信息增益

信息增益等于划分前的熵减去划分后的条件熵：
Gain(D, a) = Ent(D) - Ent(D|a)。ID3 算法选择信息增益最大的属性。

## 基尼指数

CART 算法使用基尼指数：Gini(D) = 1 - sum_k p_k^2。
基尼指数不需要对数运算，因此计算更快。

## 剪枝

预剪枝在划分前判断是否值得划分，可能欠拟合。
后剪枝先建完整树再自底向上回缩，泛化性能通常更好，但训练开销更大。
