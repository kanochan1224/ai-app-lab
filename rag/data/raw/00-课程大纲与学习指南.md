# 《机器学习导论》课程大纲与学习指南

## 课程基本信息

- **课程代码**：CS3012
- **学分/学时**：3 学分 / 48 学时（理论 32 + 实验 16）
- **授课对象**：计算机科学与技术、人工智能、数据科学专业本科三年级
- **先修课程**：高等数学、线性代数、概率论与数理统计、Python 程序设计
- **考核方式**：平时作业 20% + 实验报告 30% + 期末闭卷考试 50%

## 课程目标

学完本课程后，学生应当能够：

1. 用自己的话解释监督学习与无监督学习的区别，并判断一个实际问题属于哪一类；
2. 对给定数据集完成「数据清洗 → 特征工程 → 模型训练 → 评估调优」的完整流程；
3. 推导线性回归的最小二乘解、逻辑回归的梯度公式、决策树的信息增益公式；
4. 读懂 scikit-learn 主要估计器的 API，理解 `fit` / `predict` / `transform` 三个方法的分工；
5. 判断一个模型是否过拟合，并说明为什么；能针对过拟合选择合适的应对手段；
6. 阅读一篇机器学习方向的会议论文摘要，说明它解决的问题与采用的方法。

## 各章核心问题

### 第 1 章 概述与数学基础

什么是学习？机器学习的三个要素（模型、策略、算法）分别指什么？
为什么需要把数据划分为训练集与测试集？最小二乘、极大似然、最大后验三种估计
在什么条件下等价？

### 第 2 章 线性模型

线性回归的假设是什么？最小二乘解的闭式表达 $w = (X^\top X)^{-1} X^\top y$
在什么情况下会失效？岭回归如何缓解这个问题？逻辑回归为什么用交叉熵而不是均方误差？

### 第 3 章 决策树

信息熵、条件熵、信息增益、信息增益率、基尼指数这几个概念之间的关系是什么？
ID3、C4.5、CART 三代算法的差别在哪？预剪枝与后剪枝各自的优缺点？

### 第 4 章 模型评估与选择

为什么不能直接用训练误差估计泛化误差？交叉验证解决了什么问题，代价是什么？
准确率在类别不平衡时为什么会骗人？PR 曲线与 ROC 曲线分别适合什么场景？
偏差-方差分解告诉我们模型复杂度与误差之间的什么关系？

### 第 5 章 支持向量机

最大间隔分类器的几何直觉是什么？为什么原问题难解而要转成对偶问题？
核技巧解决了什么？软间隔的惩罚系数 $C$ 变大变小分别会怎样？

### 第 6 章 神经网络

单层感知机为什么连 XOR 都学不会？多层前馈网络 + 反向传播如何解决这个问题？
梯度消失是怎么产生的？ReLU 为什么能缓解它？

### 第 7 章 集成学习

Bagging 与 Boosting 的核心差别是什么？随机森林的「随机」体现在哪两处？
AdaBoost 为什么能降低偏差？GBDT 与 XGBoost 的主要改进点有哪些？

### 第 8 章 无监督学习

K-means 的目标函数是什么，为什么只能保证收敛到局部最优？
如何选择 K？DBSCAN 相比 K-means 的适用场景差异？
PCA 为什么可以用协方差矩阵的特征向量来解释？

## 学习建议

- 每章结束后**必须动手写代码**，只读不写是学不会机器学习的；
- 数学推导不要跳过，考试与面试都会问「为什么」；
- 遇到公式先问三个问题：这个符号代表什么数据、这个假设是否合理、边界情况会怎样；
- 实验报告要求写清「你观察到了什么现象」而不是「你调用了什么函数」。

## 常见误区

1. **把准确率当唯一指标**：在 99% 负样本的数据集上，全猜负类也有 99% 准确率。
2. **在测试集上调参**：反复用测试集评估并选模型，测试集就变成了验证集，泛化估计会偏乐观。
3. **不做特征标准化就上 SVM/KNN**：距离度量会被量纲大的特征主导。
4. **数据泄漏**：在划分训练测试集之前就做了归一化或填充缺失值。
5. **盲目上深度学习**：表格数据上，XGBoost 往往比深度网络更强且更快。
