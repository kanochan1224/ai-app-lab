# 第 6 章 神经网络与深度学习初步

## 6.1 从感知机说起

### 6.1.1 神经元模型

神经网络最基本的单元是**神经元**（M-P 神经元模型）：接收 $n$ 个输入信号，
加权求和后与阈值比较，再经过激活函数输出：

$$
y = f\left(\sum_{i=1}^{n} w_i x_i - \theta\right)
$$

理想中的激活函数是阶跃函数（0 或 1），但它不连续、不可导，
无法用梯度方法学习。因此实际使用 **Sigmoid** 等连续可导函数：

$$
\mathrm{sigmoid}(z) = \frac{1}{1 + e^{-z}}
$$

### 6.1.2 感知机与它的致命局限

单层感知机由输入层与一个输出神经元组成，只能解决**线性可分**问题。
它的学习规则很简单：对每个样本，若分类正确则不改权重，
若分类错误则按 $w_i \leftarrow w_i + \eta y x_i$ 更新。可以证明：
**只要数据线性可分，感知机一定能在有限步内收敛**（Novikoff 定理）。

但 Minsky 与 Papert 在 1969 年指出：单层感知机连 XOR（异或）都学不会。
原因是 XOR 的正负样本在二维平面上呈对角分布，不存在一条直线能把它们分开。

**直觉解释**：一层线性变换 + 单调激活，其决策边界仍是超平面。
要表达 XOR，必须先做一个「非线性特征变换」把样本变得线性可分。

### 6.1.3 多层前馈网络

在输入层与输出层之间加入**隐层**（hidden layer），就得到多层前馈神经网络
（multilayer feedforward neural network，也常称多层感知机 MLP）。
每层神经元与下一层全连接，同层之间、跨层之间都没有连接，信号单向传播。

**为什么加一层就能解决 XOR？**
以两个隐层神经元为例，令它们分别学习「$x_1$ 或 $x_2$」与「$x_1$ 且 $x_2$」，
输出层再组合这两个中间结果即可表达 XOR。
本质上是隐层把原始空间映射到了新的特征空间，在新空间里 XOR 变成线性可分的。

**通用近似定理**（universal approximation theorem）：
只要隐层神经元足够多，单隐层前馈网络就能以任意精度逼近任意连续函数。
这解释了 MLP 的表达能力，但注意它**只保证存在性，不保证可学到**。

## 6.2 反向传播算法

### 6.2.1 基本思想

训练 MLP 需要确定所有权重与阈值。反向传播（error BackPropagation，BP）
基于梯度下降：**先前向计算输出，再反向传播误差梯度，沿负梯度方向更新参数**。

关键在于链式法则让我们能高效地计算每个参数的偏导——
从输出层往前逐层算，每一步复用后面算过的结果，复杂度与前向传播同阶。

### 6.2.2 梯度推导（以均方误差为例）

设第 $l$ 层第 $j$ 个神经元的输出为 $a_j^l = f(z_j^l)$，
$z_j^l = \sum_k w_{jk}^l a_k^{l-1} + b_j^l$。定义误差项
$\delta_j^l = \partial E / \partial z_j^l$，损失
$E = \frac{1}{2}\sum_j (a_j^L - y_j)^2$。

**输出层**（$l = L$，输出层用恒等激活）：

$$
\delta_j^L = a_j^L - y_j
$$

**隐层反向递推**：

$$
\delta_j^l = \left(\sum_k w_{kj}^{l+1} \delta_k^{l+1}\right) f'(z_j^l)
$$

**参数梯度**：

$$
\frac{\partial E}{\partial w_{jk}^l} = \delta_j^l a_k^{l-1},
\qquad
\frac{\partial E}{\partial b_j^l} = \delta_j^l
$$

更新规则即 $w \leftarrow w - \eta \frac{\partial E}{\partial w}$，$\eta$ 为学习率。

### 6.2.3 常见损失函数

| 任务 | 损失函数 | 说明 |
| --- | --- | --- |
| 回归 | 均方误差 MSE | 对异常值敏感 |
| 回归 | 平均绝对误差 MAE | 更稳健，但在 0 点不可导 |
| 二分类 | 二元交叉熵 BCE | 与 Sigmoid 搭配，梯度不会饱和 |
| 多分类 | 交叉熵 + Softmax | PyTorch 的 `CrossEntropyLoss` 已内含 Softmax |

注意：PyTorch 的 `nn.CrossEntropyLoss` = `LogSoftmax` + `NLLLoss`，
所以模型最后一层**不要**再加 Softmax，否则会重复计算导致结果错误。

## 6.3 激活函数

| 函数 | 表达式 | 优点 | 缺点 |
| --- | --- | --- | --- |
| Sigmoid | $1/(1+e^{-z})$ | 输出在 (0,1)，可解释为概率 | 两端饱和，梯度消失；输出非零均值 |
| Tanh | $(e^z - e^{-z})/(e^z + e^{-z})$ | 零均值，收敛比 Sigmoid 快 | 仍会饱和 |
| ReLU | $\max(0, z)$ | 计算极快；正区间梯度恒为 1，缓解梯度消失 | 负区间梯度为 0，可能「神经元死亡」 |
| Leaky ReLU | $\max(\alpha z, z)$ | 修复死亡问题 | 需调 $\alpha$ |
| GELU / SiLU | 平滑版 ReLU | Transformer 中常用 | 计算稍贵 |

**梯度消失的成因**：Sigmoid 的导数最大只有 0.25，
反向传播时每层都要乘一个 $\le 0.25$ 的因子，层数一多梯度就指数级衰减到接近 0，
浅层参数几乎不更新。ReLU 在正区间导数为 1，梯度可以「无损」传回去，
这就是它在深层网络中取代 Sigmoid 的核心原因。

**神经元死亡**：若某神经元的加权输入长期为负，ReLU 输出恒为 0，
梯度也为 0，该神经元再也不更新。缓解手段：用 Leaky ReLU、
减小学习率、或加 Batch Normalization。

## 6.4 输出层与损失函数的搭配

- **回归**：输出层恒等（1 个神经元），损失用 MSE；若目标有正负且幅度大，
  也可用 Huber 损失。
- **二分类**：输出层 1 个神经元 + Sigmoid，损失用 BCE。
- **多分类**：输出层 $K$ 个神经元，配交叉熵（内部做 Softmax）。
- **多标签**：输出层 $K$ 个神经元 + 每个都用 Sigmoid，损失用 BCE（各类别独立）。

## 6.5 优化方法与训练技巧

### 6.5.1 从 SGD 到 Adam

| 优化器 | 核心思想 | 特点 |
| --- | --- | --- |
| BGD | 用全部样本算梯度 | 稳定但慢，内存吃紧 |
| SGD | 用单个样本算梯度 | 快但震荡剧烈 |
| Mini-batch SGD | 用一批样本 | 实践默认，兼顾稳定与效率 |
| Momentum | 累积历史梯度方向 | 抑制震荡，加速收敛 |
| RMSProp | 按梯度平方的滑动平均缩放学习率 | 适合非平稳目标 |
| Adam | Momentum + RMSProp + 偏差校正 | 默认首选，对学习率不敏感 |

### 6.5.2 缓解过拟合

1. **早停**（early stopping）：在验证集误差开始上升时停止训练；
2. **正则化**：L2（weight decay）让权重变小；L1 产生稀疏权重；
3. **Dropout**：训练时随机丢弃一部分神经元，迫使网络不依赖单个神经元，
   相当于集成大量子网络；**预测时必须关闭**；
4. **数据增强**：图像翻转/裁剪、文本同义替换等，本质是扩充有效样本；
5. **Batch Normalization**：对每层输入做标准化，允许更大学习率，
   本身也带轻微正则效果；
6. **减小模型容量**或**增加训练数据**。

### 6.5.3 参数初始化

- 全零初始化：所有神经元梯度相同，对称性无法打破，网络学不到东西；
- 小随机数：早期做法，层数深时仍会梯度消失；
- **Xavier 初始化**：方差取 $2/(n_{in} + n_{out})$，适合 Tanh/Sigmoid；
- **He 初始化**：方差取 $2/n_{in}$，适合 ReLU。

## 6.6 深度学习为什么现在才火

神经网络的理论在 1980 年代就已成型，直到 2010 年代才爆发，原因有三个：

1. **数据**：ImageNet 等大规模标注数据集出现；
2. **算力**：GPU 并行计算让矩阵运算快了几十甚至上百倍；
3. **算法与工程**：ReLU、Dropout、BatchNorm、Adam、残差连接等技巧
   解决了深层网络难以训练的问题。

这提示我们：**模型能力、数据规模、计算资源三者缺一不可**，
这也是分析任何 AI 系统时都该具备的视角。

## 6.7 本章要点回顾

- 单层感知机只能处理线性可分问题，加隐层即可表达 XOR；
- BP 用链式法则高效计算所有参数的梯度，是深度学习的基石；
- 激活函数的选择直接影响梯度能否有效回传，ReLU 家族是当前默认；
- 输出层与损失函数必须搭配正确，否则训练会「看起来很对但学不好」；
- 过拟合的应对是组合拳：早停 + 正则 + Dropout + 更多数据。
